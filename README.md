# Time Playground — Godot 4

Базовая 2D-песочница в духе People Playground. Один тип объекта — деревянный ящик; гравитация, столкновения, пол, боковые границы и фон с сеткой. Ассеты и плагины не требуются.

## Запуск

Открыть `project.godot` в Godot 4.6 и нажать **F6/F5** (главная сцена — `scenes/main.tscn`), либо выполнить из каталога проекта:

```sh
godot --path .
```

## Управление

| Клавиша | Действие |
| --- | --- |
| Q | Создать вертикальный ящик у курсора |
| E | Создать горизонтальный ящик у курсора |
| ЛКМ | Выбрать и удерживать объект за точку захвата; отпустить для броска |
| A / D | Вращать выбранный объект влево / вправо |
| T | Переключить обычное время / замедление ×0.2 |
| Пробел | Пауза физики; интерфейс и создание объектов остаются доступны |
| Delete | Удалить выбранный объект |
| R | Очистить сцену и вернуть один ящик |

Клавиши привязаны к физическим позициям, поэтому работают и при русской раскладке. Выделение сохраняется после отпускания мыши. Спавн ограничен областью над полом.

Перетаскивание использует ограниченную упругую силу и демпфирование в `_integrate_forces`, а не телепортацию. Скорость точки захвата учитывает вращение; захват за край создаёт вращающий момент. При отпускании линейная и угловая скорости сохраняются. Замедление меняет `Engine.time_scale`, сохраняя физику в модельном времени.

## Проверка

```sh
godot --headless --path . --script tests/smoke.gd
```

Тест проверяет гравитацию, пол, подъём пружиной, сохранение импульса при броске, вращение, замедление, паузу, сброс, Q/E и удаление. Для визуальной проверки интерфейса и ощущения управления запустите проект в редакторе.

## Структура

- `scripts/playground.gd` — сцена, управление, спавн, интерфейс, время.
- `scripts/prop.gd` — RigidBody2D, форма, отрисовка, захват и вращение.
- `tests/smoke.gd` — интеграционные проверки физики.

Это основа песочницы: персонажи, повреждения и сохранение сцен пока не реализованы.
