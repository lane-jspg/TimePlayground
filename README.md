# Time Playground — Godot 4.6

2D-физическая песочница: предметы, регдолл, верёвки, сварка, электрические цепи и программируемый CPU.

## Запуск

Открыть `project.godot` в Godot 4.6, нажать **F5**, затем **Play**. Или:

```sh
godot --path .
```

Иконка в палитре **только выбирает тип**. Для создания наведите курсор на мир и нажмите **Q** или **E**. При старте на сцене один ящик.

Категории слева:

- **Objects** — ящик, колесо, бутылка, серый регдолл.
- **Gates** — AND, NOT, OR, XOR.
- **Electronics** — CPU и рычаг (Lever).

Исходные SVG первого набора сохранены без изменений в `assets/source/`. Новые изображения логических элементов и категорий воссозданы в векторном стиле по присланным примерам; рычаг и недостающие spawn-кнопки нарисованы в том же стиле. Редактируемые SVG и готовые PNG новых элементов находятся в `assets/textures/`.

## Управление

| Действие | Результат |
| --- | --- |
| Q / E | Создать выбранный тип у курсора; E поворачивает обычный предмет на 90° |
| ЛКМ по предмету | Схватить; отпустить для броска с сохранением импульса |
| ЛКМ с пустого места и протянуть | Рамкой выбрать несколько объектов |
| A / D | Вращать выбранный объект |
| Пробел | Пауза / возобновление физики |
| G | Замедление ×0.2 / обычное время |
| R | Удалить выделенные объекты; регдолл удаляется целиком |
| F | Activate / Deactivate выбранных электронных объектов |
| C / V | Copy / Paste группы; вставка у курсора |
| ПКМ | Контекстное меню объекта/группы; Paste доступен и на пустом месте |
| Стрелки / зажатое колёсико | Двигать камеру; ручное движение прекращает Follow |
| Clear Everything | Удалить все объекты и соединения; содержимое буфера копирования сохраняется |
| Escape | Закрыть редактор/диалог/меню или открыть главное меню |

Клавиши физические: работают и с русской раскладкой. При вводе GDScript и чисел игровые хоткеи блокируются. Рамки при обычном захвате предмета нет; рамка появляется при выделении с пустого места и показывает выбранную группу.

## Контекстное меню

- **Freeze / Unfreeze** — заморозить/разморозить объект или выбранную группу. Замороженные объекты можно двигать и вращать **только на паузе**. Работающее время и замедление не разрешают их редактирование.
- **Follow / Unfollow** — следовать камерой за объектом.
- **Activate / Deactivate** — включить/выключить рычаг, логический элемент или CPU; то же действие — F.
- **Flip** — зеркально отразить предмет/группу. У регдолла отражается текущая физическая поза.
- **Copy / Paste** — копировать и вставлять. Сохраняются размеры, отражение, Freeze, программа CPU, состояние рычага, позы регдоллов и соединения внутри группы. Связи с объектами вне группы не копируются. Вставленные объекты получают нулевой импульс.
- **Disconnect** — убрать соединения выбранных объектов.
- **Delete** — удалить выделенное.
- **Resize** — X/Y от 0 до 100: 50 = исходный размер, 100 = двойной. Значение 0 даёт минимальную коллизию 1% для устойчивости физики. Apply применяет, Cancel отменяет.
- **Edit instructions** — открыть редактор программы CPU (пункт появляется у CPU).

На паузе физика, электрические сигналы и программы остановлены; интерфейс, камера и редактирование объектов продолжают работать. До паузы сохраняется импульс, Freeze обнуляет его. Перемещение на паузе не создаёт броскового импульса.

При Resize регдолла пересоздаются части и суставы: поза возвращается к исходной, внешние соединения отсоединяются. Freeze, отражение и пауза сохраняются. Обычный Resize предметов сохраняет соединения и масштабирует точки крепления.

## Верёвка, сварка и провода

Выбор инструмента — **справа внизу**. **Hand** возвращает обычный захват и выделение.

Выберите **Rope**, **Weld** или **Wire**, нажмите ЛКМ на первый предмет, затем на второй. Щелчок по пустому месту сбрасывает незавершённое соединение. Можно соединять в выбранных точках, а не только по центру.

- **Rope** — ограничивает максимальное расстояние, может провисать и позволяет предметам качаться. Для неподвижной опоры заморозьте один предмет.
- **Weld** — жёсткая сварка: сохраняет взаимное расстояние и угол предметов.
- **Wire** — передаёт сигнал **от первого предмета ко второму**, направление показано стрелкой. Физически предметы не связывает. Зелёный цвет означает активный сигнал.

Точки крепления следуют за движением, размером и отражением предметов. Удаление объекта удаляет его соединения. Copy/Paste копирует соединения, если обе стороны входят в выделенную группу.

## Электричество и логика

Выберите и создайте **Lever**, вернитесь в **Hand**, выберите рычаг и нажмите **F** либо **Activate**. Активный рычаг создаёт сигнал без входящего питания.

Соедините Wire от рычага к логическому элементу/CPU. Входами служат все провода, направленные **в** элемент, выход отправляется по всем исходящим проводам:

| Элемент | Выход |
| --- | --- |
| AND | Все подключённые входы включены |
| NOT | Инверсия первого подключённого входа |
| OR | Хотя бы один вход включён |
| XOR | Нечётное количество включённых входов |
| CPU | Определяется программой, пока есть входящий сигнал |

Без входящих проводов логический элемент выключен. NOT с подключённым, но обесточенным входом включён. Несколько проводов в NOT используют первый вход; для остальных логических элементов учитываются все подключённые входы. Обычный предмет передаёт любое поступившее питание дальше.

Передача синхронная: каждый провод добавляет один физический такт задержки. Обратные связи тоже обновляются по тактам. При 120 Гц это около 8.3 мс на ступень в обычном времени.

## CPU / Edit instructions

ПКМ по CPU → **Edit instructions**. Мир остановится на время редактирования. Программа — GDScript, наследующий `RefCounted`, с методом `tick(cpu, delta)`. Он вызывается каждый физический такт, пока на CPU поступает ток и CPU включён. Состояние экземпляра программы сохраняется между тактами.

```gdscript
extends RefCounted

var elapsed := 0.0

func tick(cpu, delta: float) -> void:
    elapsed += delta
    # Пример мигающего выхода, когда CPU получает ток.
    cpu.output_power = fmod(elapsed, 1.0) < 0.5
```

`cpu.powered` — наличие входного сигнала; `cpu.output_power` — выход для последующих проводов. Доступны обычные методы Godot, например `cpu.apply_central_force(...)` и `cpu.set_meta(...)`.

**Apply instructions** компилирует код. При ошибке редактор остаётся открытым и показывает сообщение; предыдущая рабочая программа сохраняется. Конструктор новой программы и `tick` не запускаются до подачи питания. Отключение тока прекращает вызовы и сбрасывает выход.

Это нативный GDScript с доступом к Godot API. Каждый вызов `tick` должен завершаться; бесконечный цикл остановит игровой поток. Ошибки выполнения выводятся в Godot Output. Это редактор локальных программ, а не изолированная среда выполнения.

## Регдолл

11 физических частей, 10 суставов. Исключения самоколлизий заданы в обе стороны для всех 110 пар направлений, включая соседние части после создания суставов, Resize и Flip. Пол и чужие предметы продолжают сталкиваться с телом. Простой ИИ балансирует на земле и делает небольшие шаги; захват, пауза, Freeze и отсутствие опоры отключают управление. Навигации и повреждений пока нет.

godot --headless --path . --script tests/ragdoll_smoke.gd

```sh
godot --path . --script tests/ui_smoke.gd
```

Тесты проверяют физику и суставы, отсутствие самоколлизий, Freeze/паузу, палитру без спавна, выделение/копирование соединённых групп, верёвку/сварку, таблицы истинности, направленную передачу тока, программы CPU и интерфейс.
