# Time Playground — Godot 4.6

2D-физическая песочница: ящик, колесо, бутылка и тестовый серый регдолл. Оформление использует предоставленные SVG. Исходники сохранены без изменений в `assets/source/`, готовые PNG — в `assets/textures/`. PNG нужны для корректного отображения SVG-текста и встроенных растровых изображений в Godot; для запуска Inkscape не требуется.

## Запуск

Открыть `project.godot` в Godot 4.6 и нажать **F5**, затем **Play**. Или из каталога проекта:

```sh
godot --path .
```

В меню **Objects** нажмите иконку ящика, колеса, бутылки или кнопку **Ragdoll**: объект появится в центре камеры, а его тип станет активным для Q/E. При первом запуске на сцене один ящик.

## Управление

| Клавиша / действие | Результат |
| --- | --- |
| Q / E | Создать выбранный тип у курсора; E поворачивает обычные предметы на 90° |
| ЛКМ | Схватить объект; отпустить для броска с сохранением импульса |
| A / D | Вращать выбранный объект |
| Пробел | Остановить / возобновить физику |
| G | Замедление ×0.2 / обычное время |
| R | Удалить выбранный объект (регдолл удаляется целиком) |
| C | Очистить все объекты, включая регдоллов |
| ПКМ по объекту | Контекстное меню |
| Стрелки | Перемещать камеру |
| Зажатая средняя кнопка мыши | Перетаскивать камеру |
| Escape | Закрыть диалог / контекстное меню / открыть или закрыть главное меню |

Клавиши привязаны к физическим позициям и работают при русской раскладке. Ввод чисел в Resize не вызывает игровые хоткеи. Нижних подсказок и линии пружины нет.

## Объекты и время

- **Freeze / Unfreeze** — остановить отдельный объект. Для регдолла действует на все части.
- **Follow / Unfollow** — камера плавно следует за объектом. Ручное перемещение камеры отключает слежение.
- **Delete** — удалить объект.
- **Resize** — независимо изменить X/Y в пределах 0–100; **50 = исходный размер**, 100 = двойной. Нулевое значение даёт минимальный размер 1%, чтобы коллизия оставалась корректной. Apply применяет изменения, Cancel или Escape отменяет.

При паузе и Freeze объекты можно перемещать мышью и поворачивать A/D. При паузе сохраняются скорости до остановки; редактирование не добавляет бросковый импульс. Freeze обнуляет скорость. В обычном времени захват использует невидимую упругую силу с демпфированием, поэтому столкновения и импульс при отпускании сохраняются.

Форма коллизии меняется вместе с текстурой при Resize; колесо получает эллиптическую коллизию при разных X/Y. При ресайзе регдолла части и суставы пересоздаются вокруг торса, поза возвращается к исходной; Freeze, пауза и слежение сохраняются.

Тестовый регдолл состоит из 11 физических частей и 10 суставов. Простой ИИ пытается балансировать и двигаться, меняет направление каждые пять секунд. В воздухе, при захвате, паузе и заморозке управление ИИ отключается. Это физический прототип, а не полноценный персонаж с навигацией или повреждениями.

Фон и поверхность пола используют предоставленную текстуру сетки; пол обозначен её более тёмным вариантом. Камера и меню работают с обычной скоростью при замедлении.

## Проверка

```sh
godot --headless --editor --path . --import --quit
godot --headless --path . --script tests/smoke.gd
godot --headless --path . --script tests/ragdoll_smoke.gd
```

Дополнительная проверка реальных кликов по интерфейсу (требуется графический дисплей):

```sh
godot --path . --script tests/ui_smoke.gd
```

Тесты проверяют физику, захват и импульс, редактирование на паузе, Freeze/Unfreeze, меню, Resize, камеру, хоткеи, части регдолла и суставы. Визуальную проверку можно повторить через обычный запуск проекта.

Повторная конвертация арта (нужен Inkscape):

```sh
python3 tools/prepare_assets.py
```

## Структура

- `scripts/playground.gd` — сцена, меню, камера, управление, спавн и время.
- `scripts/prop.gd` — физические предметы, текстуры, захват и изменение коллизий.
- `scripts/ragdoll.gd` — суставы и простой ИИ.
- `assets/source/` — оригинальные SVG пользователя.
- `assets/textures/` — готовые текстуры для Godot.
- `tests/` — интеграционные проверки.
